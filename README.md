# Java Console Calculator

## Overview

This project is a basic **Java Console Calculator** developed using Java and run in **VS Code**.

The calculator performs four basic arithmetic operations:

* Addition
* Subtraction
* Multiplication
* Division

## Technologies Used

* Java (JDK)
* VS Code
* Java `Scanner` for console input

## Features

* Takes numbers and operation choices from the user.
* Uses separate methods for each arithmetic operation.
* Uses a loop to allow multiple calculations.
* Handles division by zero.
* Provides an option to exit the calculator.

## How to Run

1. Open the project in VS Code.
2. Compile the Java file:

   ```bash
   javac Calculator.java
   ```
3. Run the program:

   ```bash
   java Calculator
   ```
4. Select an operation and enter the required numbers.
5. Select **5** to exit.
